📚 Book Management System

A simple Book Management System built to manage books efficiently using basic CRUD operations.

📌 Features

Add new books

View list of books

View detailed book information

Edit existing books

Delete books

🗂️ Database Structure
Table: books
Field	Description
id	Primary key
isbn	Unique ISBN-13 (auto-generated)
title	Book title
author	Book author
genre	Category (Fiction, Nonfiction, Mystery, Biography, Sci-Fi)
publication_year	Year of publication
price	Book price
created_at	Record creation timestamp
updated_at	Record last update timestamp
🔄 CRUD Operations
➕ Create

Add a new book using a form

Automatically generates a unique ISBN-13

📖 Read

Display a list of all books

View detailed information of a selected book

✏️ Update

Edit book details through an update form

❌ Delete

Remove a book from the system
